[1] NAMA APLIKASI (Maks 30 karakter):
LeuwiPanjang - SSH Client

[2] DESKRIPSI SINGKAT (Maks 80 karakter):
Klien SSH ringan untuk Android: login key Ed25519/RSA, terminal ANSI & snippet.

[3] DESKRIPSI LENGKAP (Maks 4000 karakter):
LeuwiPanjang adalah klien SSH dan emulator terminal untuk Android yang ringan, cepat, dan open source. Dibuat untuk DevOps, sysadmin, dan developer yang perlu mengakses server Linux dari mana saja.

Dibangun 100% native dengan Kotlin, tanpa iklan, tanpa pelacakan, dan ukuran aplikasi di bawah 10 MB.

FITUR UTAMA

🔑 Autentikasi SSH Key (Key Vault)
• Buat pasangan kunci Ed25519 (direkomendasikan) atau RSA 2048/4096-bit langsung di HP.
• Import private key format OpenSSH atau PEM/PKCS#8, termasuk yang dilindungi passphrase.
• Salin public key dengan satu ketukan untuk ditambahkan ke ~/.ssh/authorized_keys.
• Salin perintah satu baris yang langsung memasang public key di server.
• Tampilkan fingerprint SHA-256 untuk verifikasi kunci.

🖥️ Terminal Interaktif
• Dukungan warna ANSI 16 dan 256 warna.
• Baris tombol tambahan di atas keyboard: ESC, TAB, CTRL, ALT, tombol panah, PgUp/PgDn, simbol | / ~ - :, serta ^C dan ^D.
• Bisa dipakai untuk aplikasi layar penuh seperti htop, vim, dan nano.
• Empat tema terminal dan ukuran font yang bisa diatur.

🌐 Manajer Host
• Simpan server tanpa batas: alias, hostname/IP, port, username, dan grup.
• Login dengan SSH key atau password.
• Quick Connect: buka sesi langsung dari daftar host.

⚡ Snippet Perintah
• Simpan perintah yang sering dipakai, misalnya docker ps, df -h, git pull, atau systemctl status nginx.
• Kirim snippet ke sesi terminal aktif tanpa mengetik ulang.

🔒 Privasi
• Semua host, password, dan private key hanya disimpan di perangkat Anda.
• Koneksi langsung dari HP ke server Anda, tanpa server perantara.
• Tidak ada iklan, analitik, atau SDK pelacak pihak ketiga.
• Kode sumber terbuka di GitHub (lisensi GPLv3): github.com/leuwipanjang/leuwipanjang

[8] DEKLARASI FOREGROUND SERVICE (App content > Foreground service permissions):
- Jenis: Special use (FOREGROUND_SERVICE_SPECIAL_USE)
- Deskripsi fitur (EN):
  LeuwiPanjang is an SSH client. When the user opens an interactive terminal session to
  their own server, a foreground service keeps that network connection alive while the user
  switches to another app or the screen turns off, so running commands are not interrupted.
  The service starts only from a user-initiated connection, shows an ongoing notification
  listing the active sessions with a "Disconnect all" action, and stops as soon as the last
  session is closed. No other foreground service type fits a user-controlled, long-running
  interactive remote shell, and dataSync is time-limited on Android 15+.
- Dampak bila ditunda/dihentikan sistem: koneksi SSH terputus, perintah yang sedang berjalan
  di server berhenti, dan pengguna kehilangan sesi interaktifnya.
- Video demo: buka host, jalankan perintah, tekan Home / matikan layar, kembali ke aplikasi
  (sesi masih tersambung), lalu tunjukkan notifikasi dan tombol "Disconnect all".
